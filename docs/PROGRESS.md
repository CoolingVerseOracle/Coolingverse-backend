## 1. ERD 설계 확정 (7/21 ~ 7/28)

- **7/21 팀 회의 반영:** `household_cnt`(세대수) 삭제, `day_of_week`(요일) 추가,
  시나리오 결과를 `scenario_results` 별도 테이블로 분리 (같은 조건의 재계산 이력을 쌓는 구조)
- **7/26 데이터분석 최종 CSV 5종 수령 → 전수 검증:** 5개 파일 헤더·데이터를 ERD와
  하나하나 대조. 격자 12만 행, 단속 16만 행 등 실물 기준으로 구조 확정
- **최종 8테이블 확정:** `parking_idle` 제외(유휴율 29.1%가 open_count에 사전 반영됨),
  위험지수 가중치 갱신(0.35 공급부족 + 0.25 수요압력 + 0.15 교통혼잡 + 0.25 환경민감도, ×100),
  격자 = 국가지점번호 100m×100m 확정
- **프론트 정렬(7/28):** scenarios 컬럼을 프론트 화면 필드와 1:1로 재편
  (개방대상 체크박스 2개, 운영시간 "HH:mm", 상업반경 추가)
- **시드 SQL 변환:** 데이터분석 시드를 새 컬럼 구조로 변환(수치 동일) +
  자동번호(IDENTITY) 충돌 버그 발견·수정 (`db/seed.sql`)

## 2. 로그인 방식 전환: 세션 → 정적 토큰 (7/28)

프론트 프로토타입 코드 분석 결과 토큰 방식을 전제하고 있어, 프론트 계약에 맞춰 전환.

- `POST /login` → `{success, token}` 응답 (실패도 200 + `success:false`, 프론트 처리 방식에 맞춤)
- `TokenStore`(기동 시 SecureRandom 토큰 생성) + `TokenAuthFilter`(Bearer 헤더 검사) 신규
- `SecurityConfig` 재작성: 무상태(stateless), `/login`만 공개, 미인증 401, CORS(5173 허용)
- BCrypt 해시 대조·환경변수 주입 등 기존 비밀번호 보호는 그대로 유지
- 상세: [SECURITY.md](./SECURITY.md) 참고

## 3. API 구현 (7/28)

| API | 내용 | 검증 |
| --- | --- | --- |
| `POST /simulate` | What-If 계산 (규칙 기반 수식) | 분석 가이드 5단계 표 15개 수치 소수점까지 재현 |
| `GET /simulate/initial` | 대시보드 첫 화면 기본 결과 (30%, 08~19시) | KPI 5장 등 프론트 타입과 1:1 |
| `GET /scenarios` | 목록 (검색·정렬·페이지네이션 서버 처리) | 한글 검색 포함 실호출 검증 |
| `POST /scenarios` | 저장 (결과 스냅샷 즉석 계산해 함께 보관) | 45% 보간 수치 검증 |
| `GET/DELETE /scenarios/{id}` | 상세 조회 / 삭제 | 404 처리 확인 |

- 응답 JSON은 프론트 타입 파일(simulation.ts, scenario.ts)과 1:1 — mock 교체만 하면 연동됨
- 저장소는 임시 메모리(`ScenarioStore`, 서버 재시작 시 시드 5건으로 초기화) — ADB 후 DB 교체 예정

## 4. 품질 · 검증 (7/28)

- **단위 테스트 약 20개:** 분석 표 5단계 재현, 보간(45%), 야간 운영시간, 참여율 경계값,
  로그인 성공/실패/누락 4종, 시나리오 저장 검증 등 — `gradlew test` 한 번으로 자동 검증

  미개방 193단지 잠재 유휴면 합계 39,114면 실측 일치
- **입력 방어:** 자정 넘긴 운영시간(22:00~06:00) 음수 계산 수정, 로그인·시나리오
  필수값 누락 시 500 대신 안내 응답

## 5. DB 연동 준비 (7/28)

- JPA 엔티티 8종 + 리포지토리 4종 작성 (ERD와 1:1, 코드 상수를 대체할 집계 쿼리 포함)
- 기본 프로필 = H2 메모리 DB (엔티티 매핑 검증용), `oracle` 프로필 = ADB Wallet 연결 템플릿
- ADB 권한이 풀리면: Wallet 경로·계정 채우기 → `db/schema.sql`+`seed.sql` 실행 → CSV 적재 → 저장소 교체
